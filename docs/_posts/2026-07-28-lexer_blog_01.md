# Standalone Lexer

Well the previous Z lexer design was somehow like every other lexer design, take a source buffer, either a `FILE` stream or a raw string stream, imagine we can move one way forward.

So the main idea of ZLexer is:

```cpp
ZLexer lexer(source_chunk_1);
bool need_more_source = false;
// If last token is complete need_more_source is false but if it's unterminated returns true.
need_more_source = lexer.lex();
lexer.swap_buffer(source_chunk_2);
lexer.lex();

std::vector<ZLexerToken> tokens = lexer.finalize();
lexer.diagnostics() // pass this to diagnostics section.
```
